# Ekologiya fani — amaliy mashg'ulot materiallari

Ushbu papkada "Ekologiya" fanidan 15 ta amaliy/laboratoriya mashg'uloti uchun tayyorlangan
metodik hujjatlar (.docx) saqlanadi. Har biri: mavzu, maqsad, kerakli jihozlar, qisqacha
nazariy ma'lumot, ishning bajarilish tartibi va to'ldirish uchun jadvallardan iborat.

**Holati:** bu — faqat manba materiallar arxivi. Ular hali platforma kodiga (backend/frontend)
bog'lanmagan va hech qanday funksionallikka ta'sir qilmaydi.

**Kelajakda:** loyiha rejasidagi **Phase 5 — E-learning** bosqichida (kurslar, darslar,
testlar, sertifikatlar) ushbu materiallar tizimga "kurs kontenti" sifatida kiritilishi mumkin
bo'ladi — o'shanda `Course`/`Lesson` kabi Prisma modellari loyihalanib, mazmun ma'lumotlar
bazasiga ko'chiriladi.
